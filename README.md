# Video-quality-autotest

## How to install
- ```git clone git@github.com:CHDev2116/video-quatility-autotest.git```
- ```cd /video-quality-autotest```
- ```poetry install```

## How to execute
- launch Terminal, execute
```cd src```
```python main.py```

## How to check results
- ```cd /results```, go to check HTML files.

## How to modify variables
- open variables.py, then change variables accordingly.

## Environmental settings
Create a .env file from .env.example: 

```
CONFIG_URL='https://vsp.mlytics.co/cl1lp4tbnp0kh7f95130-mlysdk.js'
ORIGIN_SRC='https://origin.p2sp.gordon.sh/stream/loop/2MHhVrzuqvuvD1AVkPo1EG1TWnF/index.m3u8'
```
